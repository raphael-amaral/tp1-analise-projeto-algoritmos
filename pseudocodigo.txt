ORDENAR(entrada, B = 100):

    1. VERIFICAR A CAPACIDADE

    Se B não for um inteiro positivo:
        informar erro e encerrar

    2. CONTAR QUANTAS VEZES CADA VALOR APARECE

    Criar um dicionário vazio chamado frequencias

    Para cada numero da entrada:
        Se numero não for um inteiro ou float finito:
            informar erro e encerrar

        Se numero ainda não existir em frequencias:
            frequencias[numero] = 1
        Senão:
            frequencias[numero] = frequencias[numero] + 1

    3. DESCOBRIR OS LIMITES DOS BLOCOS, SEM CRIAR OS VETORES AINDA

    Criar um dicionário vazio chamado blocos

    Para cada numero distinto em frequencias:
        parteInteira = piso(numero)
        idBloco = parteInteira // B

        Se idBloco ainda não existir em blocos:
            criar um registro para esse bloco
            guardar parteInteira como menorPiso do bloco
            guardar parteInteira como maiorPiso do bloco
        Senão:
            Se parteInteira for menor que o menorPiso do bloco:
                atualizar menorPiso para parteInteira

            Se parteInteira for maior que o maiorPiso do bloco:
                atualizar maiorPiso para parteInteira

    4. CRIAR UM VETOR DO TAMANHO NECESSÁRIO PARA CADA BLOCO

    Para cada bloco em blocos:
        tamanho = bloco.maiorPiso - bloco.menorPiso + 1
        criar bloco.vetor com 'tamanho' posições vazias

    5. PREENCHER OS VETORES COM OS VALORES E SUAS QUANTIDADES

    Percorrer novamente cada par (numero, quantidade) em frequencias:
        parteInteira = piso(numero)
        idBloco = parteInteira // B
        bloco = blocos[idBloco]
        indice = parteInteira - bloco.menorPiso

        Se bloco.vetor[indice] ainda estiver vazio:
            criar uma lista nessa posição

        Adicionar o par (numero, quantidade) à lista dessa posição

    6. COLOCAR OS BLOCOS EM ORDEM

    Copiar os identificadores de blocos para uma lista chamada ids
    idsOrdenados = Merge Sort de ids, do menor para o maior

    7. PERCORRER OS VETORES E MONTAR A SAÍDA

    Criar uma lista vazia chamada saida

    Para cada idBloco em idsOrdenados:
        bloco = blocos[idBloco]

        Percorrer os índices de bloco.vetor, de 0 até seu tamanho menos 1:
            Se a posição estiver vazia:
                passar para o próximo índice

            Caso contrário:
                pares = lista guardada nessa posição

                Se pares tiver mais de um elemento:
                    ordenar pares com Merge Sort pelo numero, do menor para o maior

                Para cada (numero, quantidade) em pares:
                    repetir quantidade vezes:
                        adicionar numero ao final de saida

    8. RETORNAR O RESULTADO

    Retornar saida, sem alterar a entrada


OBSERVAÇÕES

    - piso(numero) é o maior inteiro que não ultrapassa numero.
      Exemplo: piso(50.7) = 50 e piso(-1.2) = -2.

    - // é divisão inteira arredondada para baixo, como em Python.
      Exemplo: -2 // 100 = -1.

    - B define as faixas lógicas dos blocos, não o tamanho obrigatório dos vetores.
      Com B = 100, o bloco 2 representa a faixa [200, 300).

    - Se esse bloco receber apenas 240, 245 e 250:
      menorPiso = 240, maiorPiso = 250 e tamanho = 11.
      Os índices serão 0, 5 e 10. Os espaços entre eles continuam vazios.

    - Guardamos os números completos nos pares: os decimais não são arredondados.
      50.2 e 50.7 compartilham uma posição, mas continuam sendo valores distintos.

    - Valores numericamente iguais, como 2 e 2.0, compartilham uma contagem.
      Não preservamos diferenças de tipo nem o sinal de -0.0.
      NaN e infinitos são rejeitados.

    - Se a entrada estiver vazia, os percursos não executam e a saída será vazia.

    - Este pseudocódigo descreve o fluxo. Os contadores de comparações e
      movimentações serão acrescentados na etapa de instrumentação.
